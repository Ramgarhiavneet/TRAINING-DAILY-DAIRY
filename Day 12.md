DAY 12 – Save Tasks Page

Date: 7/7/2026

Today, I started developing the "Save Tasks" page of my project, Veltrix AI – Gemini. The main purpose of this page is to allow users to enter their tasks and reminders,
which can later be processed by the AI agent for automated reminder calls.

With the guidance of my project mentor, I created the basic structure of the Save Tasks page using Streamlit. I planned and added input fields where users could enter task 
descriptions and other necessary details. I also worked on planning date and time fields so that users could specify when they wanted to receive reminders.

After designing the input section, I focused on connecting task submission with MongoDB Atlas. The aim was to ensure that whenever a user submits a reminder, the information
is stored in the **tasks** collection of the Training database.

I tested the task-saving functionality to check whether the reminder information was submitted and stored correctly. I also explored how these saved tasks could later be 
accessed by the AI agent during the call execution process.

**Work Performed:**
- Created the basic structure of the Save Tasks page using Streamlit.
- Added input fields for entering task descriptions.
- Planned date and time fields for scheduling reminders.
- Connected task submission functionality with MongoDB Atlas.
- Implemented basic database operations for saving reminder information.
- Tested the task submission and saving process.
- Checked whether reminder records were stored in the **tasks** collection.

**Learning Outcome:**

Through this activity, I learned how to create a task management interface using Streamlit and connect it with MongoDB Atlas. I understood how user-entered task information
can be collected and stored for future processing. I also gained knowledge of how scheduled reminder details can be used by an AI agent to support automated calling 
functionality.
