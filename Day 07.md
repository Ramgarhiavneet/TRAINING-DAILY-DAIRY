# DAY 07 – UI Design and Customization

**Date: 30/6/2026**

Today was the seventh day of my minor project. After creating the basic Streamlit application, I started improving the design and look of Veltrix AI. With the help of my project mentor, I learned how a good user interface can make an application look better and easier to use.

My mentor suggested that the application should look modern and professional but should also be simple. We discussed different themes, colour combinations, sidebar design and page layouts. After discussing these ideas, I decided to use a dark theme for Veltrix AI.

I selected a dark background with the colour code `#0f172a`. My mentor explained that using matching colours, proper spacing and clear text helps make the application more comfortable to use.

After that, I started making changes to the Streamlit interface. I worked on arranging the sidebar so users could easily open different sections of the application. I also added Veltrix AI branding to give the project its own identity.

I also checked the layout of different pages and tried to keep their design similar. This would help users feel comfortable while moving between Save Tasks, Execute Calls and Dashboard.

During this work, I explored Streamlit's customization options. I also learned how CSS can be used to change the design of different interface components and make them look better than the default style.

**Work Performed:**

- Discussed basic UI design and matching layouts with my project mentor.
- Selected a dark theme for Veltrix AI.
- Used the dark background colour `#0f172a`.
- Explored different Streamlit design and customization options.
- Improved the layout and appearance of the sidebar.
- Added Veltrix AI branding to the application.
- Worked on arranging headings, text and other interface elements.
- Tried to keep the design similar across all application pages.
- Learned how CSS can be used to customize the interface.
- Checked the overall look of the application and noted areas that could be improved.

**Learning Outcome:**

Today, I learned why a good user interface and matching design are important in software development. I gained practical experience in changing the Streamlit theme, choosing colours and using CSS to improve the interface. With my mentor's guidance, I improved the look of Veltrix AI and created a simple and consistent dark-themed design.
