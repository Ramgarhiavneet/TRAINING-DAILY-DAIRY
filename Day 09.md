DAY 09 – MongoDB Atlas Setup

Date: 2/7/2026

Today, I worked on configuring "MongoDB Atlas" as the database for my project, Veltrix AI – Gemini. The purpose of integrating MongoDB is to store and manage important 
application data, including user contacts and reminder tasks, so that the information can be accessed whenever required.

With the guidance of my project mentor, I explored the MongoDB Atlas platform and learned how to create and configure a database cluster. I also worked on establishing a
connection between my Python application and MongoDB Atlas. This connection is important because it allows the application to communicate with the database and perform
different operations.

I planned the database structure using a database named **Training**. To keep the information organized, I decided to maintain two separate collections: "contacts" and 
"tasks". The contacts collection would store contact details required for making reminder calls, while the tasks collection would store reminder information such as task 
descriptions and related details.

I also explored basic database operations, including inserting, retrieving, updating, and deleting records. My mentor explained the importance of maintaining a proper 
database structure and protecting database credentials while connecting an application to an online database.

**Work Performed:**
- Created and configured a MongoDB Atlas cluster.
- Explored the MongoDB Atlas dashboard and database management features.
- Worked on establishing database connectivity with the Python application.
- Planned the database named **Training**.
- Designed separate **contacts** and **tasks** collections.
- Explored basic CRUD operations (Create, Read, Update, and Delete).
- Understood the importance of keeping database credentials secure.

**Learning Outcome:**

Through this activity, I learned how MongoDB Atlas can be used as a cloud-based database for storing application data. I understood the concept of databases and collections 
and how CRUD operations help manage records efficiently. I also gained practical knowledge of connecting a Python application with MongoDB Atlas and learned why database 
security is important in software development.
