# DAY 04 – Development Environment Setup

**Date:** 25/6/2026

Today was the fourth day of my minor project. After selecting the technologies, I started setting up the development environment for Veltrix AI. My project mentor explained that before writing the code, we need to install and set up all the required tools properly.

First, I checked whether Python was installed on my computer. Since Python was selected as the main programming language, I made sure that it was working properly and could be used through the terminal.

Next, I installed Visual Studio Code as my code editor. My mentor explained some useful features of VS Code, such as code highlighting, debugging, terminal support and extensions. These features help in writing and managing code more easily.

After that, I created a separate project folder named Veltrix AI to keep all the project files in one place. I also learned why it is important to keep the files and folders properly arranged during software development.

Then, I installed Streamlit and other basic Python libraries needed for the project. My mentor explained how Python packages can be installed using pip and how these packages help us add different features to an application.

At the end of the session, I created a simple Streamlit application and ran it on my computer. This helped me check whether the development environment was working properly. I also learned how to solve some basic installation and setup problems.
