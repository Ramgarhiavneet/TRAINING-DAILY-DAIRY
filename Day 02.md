# DAY 02 – Requirement Analysis

**Date:** 23/6/2026

Today was the second day of my minor project. I started working on the requirement analysis of Veltrix AI with the help of my project mentor. My mentor explained that before starting the coding work, we should clearly understand the problem and decide what features are needed in the application.

During the discussion, we talked about the people who could use an AI-based call reminder application. Many people forget their important appointments, meetings and daily tasks because of their busy schedules. My mentor suggested that the application should make it easy for users to set reminders and receive them through automatic phone calls.

I also discussed the main features of the application, such as adding reminders, saving contact details, understanding user instructions with Google Gemini and creating voice messages for reminder calls. My mentor explained the difference between functional and non-functional requirements. We also discussed some important points like ease of use, proper working, speed and security.

We then discussed the basic working of Veltrix AI. The user would enter a task using text or voice. The AI model would understand the instruction, and the application would save the required details in MongoDB Atlas. After that, the calling part of the application would make the reminder call using external services.

With the guidance of my mentor, I prepared a basic list of project requirements. This list will help me in the next steps of development.

**Work Performed:**

- Discussed the requirement analysis phase with my project mentor.
- Identified the common problems people face while remembering daily tasks and appointments.
- Defined the main purpose and features of Veltrix AI.
- Listed the functional requirements, such as adding tasks, managing contacts, understanding user instructions and making automatic calls.
- Discussed non-functional requirements like ease of use, reliability, performance and security.
- Learned about the role of Google Gemini in understanding user instructions.
- Planned to use MongoDB Atlas to store contacts and reminder details.
- Discussed using Twilio for automatic calls and ElevenLabs for voice generation.
- Explored how users could give instructions through text or voice.
- Prepared an initial list of requirements with the help of my mentor.

**Learning Outcome:**

Today, I learned why requirement analysis is important before starting software development. I understood how to identify the features of an application and the other requirements needed for its proper working. I also learned how different technologies can work together in Veltrix AI. This session helped me understand the project more clearly and prepare for the next stage of development.
