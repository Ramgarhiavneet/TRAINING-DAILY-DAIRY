# DAY 06 – Streamlit Application Development

**Date: 29/6/2026**

Today was the sixth day of my minor project. After completing the project folder structure, I started working on the basic user interface of Veltrix AI using Streamlit. With the help of my project mentor, I learned how to turn the project plan into a working web application.

My mentor explained that the user interface is an important part of any application because users interact with the system through it. We discussed how to keep the interface simple and clear so that users can easily understand and use the application.

First, I created the main Python file named `app.py`. I used Streamlit commands to set the page title, layout and basic elements. I also added the project name, Veltrix AI, to the application.

After that, I started working on the sidebar, which would help users move between different sections of the application. My mentor explained how Streamlit's sidebar and navigation features can be used to make the application easier to use.

I planned the navigation for three main sections: Save Tasks, Execute Calls and Dashboard. Each section will have its own work, but all of them will be connected to the main application.

Once the basic interface was ready, I ran the application in the VS Code terminal using the Streamlit command. I opened it in the browser and checked whether it was running properly. I also checked the layout and looked for any basic errors.
