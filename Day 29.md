DAY 29 – Functional Testing

Date:29/7/2026

Today, I started functional testing of the Veltrix AI application to verify whether its different modules were performing their intended operations. The main objective was to 
check the basic functionality of the application and identify any issues during normal usage. With guidance from my mentor, I prepared test scenarios and checked the main 
features one by one.

**Work Performed:**
- Tested application startup and checked whether the Streamlit application launched successfully.
- Tested navigation between the Save Tasks, Execute Calls, and Dashboard pages.
- Tested contact management functionality, including entering and storing contact details.
- Tested task-saving functionality using the MongoDB Atlas database.
- Checked whether saved tasks could be retrieved correctly.
- Tested basic interactions with Google Gemini.
- Observed application behaviour and noted any errors found during testing.
- Discussed testing observations and possible improvements with my mentor.

**Learning Outcome:**

I learned how to perform functional testing by checking individual application features against their expected behaviour. I also understood the importance of testing 
application startup, navigation, database operations, and AI interactions to ensure that the system works correctly.
