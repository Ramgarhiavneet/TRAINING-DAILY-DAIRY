DAY 16 – Natural Language Processing

Date: 13/7/2026

Today, I focused on improving the natural language understanding capability of my project, **Veltrix AI – Gemini**. The main objective was to make the application understand
user instructions more accurately and identify important information required for creating reminders and executing automated calls.

With the guidance of my project mentor, I tested different natural-language prompts using the Google Gemini API. I explored how Gemini could identify important details from
user instructions, such as contact names, reminder purposes, task descriptions, and scheduled dates and times.

I also worked on improving the prompt instructions to make AI responses more accurate and consistent. Special attention was given to incomplete or unclear instructions. For
example, if a user provides a reminder without mentioning the date or time, the application should be able to identify the missing information rather than making incorrect 
assumptions.

I tested different scenarios to observe how the AI model handled complete, incomplete, and differently worded commands. Based on the responses, I explored ways to improve 
the prompt structure and make the AI agent more reliable.

**Work Performed:**
- Tested different natural-language prompts using Google Gemini.
- Worked on extracting task details from user instructions.
- Improved prompt instructions for better AI understanding.
- Explored handling incomplete or unclear user instructions.
- Tested AI responses for different reminder-related scenarios.
- Checked the accuracy and consistency of extracted information.
- Discussed prompt improvements with my project mentor.

**Learning Outcome:**

Through this activity, I learned how natural language processing helps an AI application understand human instructions. I understood how prompt engineering can improve the
extraction of important task details from user input. I also learned the importance of handling incomplete instructions and validating AI-generated information before using
it in the application.
