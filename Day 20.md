DAY 20 – Execute Calls Page

Date: 17/7/2026

Today, I started developing the **Execute Calls** page of my project, Veltrix AI – Gemini. The main objective of this module is to organize and initiate automated reminder 
calls using the task and contact information already stored in the database.

With the guidance of my project mentor, I created the basic structure of the Execute Calls page using Streamlit. I focused on designing an interface where users could view 
saved reminder information and prepare for the call execution process.

I also worked on connecting the saved tasks from MongoDB Atlas with this page so that reminder details could be accessed when required. Along with this, I planned a contact
selection feature that would allow users to choose the appropriate contact associated with a reminder.

I then explored the overall calling workflow, starting from selecting a saved task and contact to preparing the information required for initiating an automated call. This
module will later be connected with the calling service to execute reminder calls.

**Work Performed:**
- Created the basic Execute Calls page using Streamlit.
- Planned the layout and components of the call execution interface.
- Worked on retrieving saved tasks from MongoDB Atlas.
- Planned contact selection for reminder calls.
- Designed the basic workflow for initiating automated calls.
- Explored the connection between saved tasks, contact details, and call execution.
- Discussed the module structure with my project mentor.

**Learning Outcome:**

Through this activity, I learned how to design a call execution interface using Streamlit. I understood how saved tasks and contact information can be connected to create an
automated calling workflow. I also gained knowledge of organizing different application modules so that they can work together to perform a complete task.
