DAY 10 – Database Integration

Date: 3/7/2026

Today, I started integrating MongoDB Atlas with my Streamlit application, Veltrix AI – Gemini. The main objective was to establish communication between the application and 
the cloud database so that reminder tasks and contact details could be stored and retrieved whenever required.

With the guidance of my project mentor, I configured the MongoDB connection in the Python application. I explored how to use the MongoDB client to connect with the "Training"
database and access its two collections: **contacts** and **tasks**.

After establishing the connection, I started implementing basic database operations. I tested inserting contact information into the contacts collection and checked whether 
the stored records could be retrieved successfully. I also explored how these operations could be used in the application to manage user information and reminder tasks.

During this process, I learned the importance of checking database connectivity and handling errors properly to ensure smooth communication between the application and the 
database.

**Work Performed:**
- Configured the MongoDB Atlas connection in the Python application.
- Connected the Streamlit application with the **Training** database.
- Accessed the **contacts** and **tasks** collections.
- Implemented basic database operations for storing and retrieving information.
- Tested inserting contact details into the contacts collection.
- Checked data retrieval from MongoDB collections.
- Explored basic error handling for database connectivity.

**Learning Outcome:**

Through this activity, I learned how to integrate MongoDB Atlas with a Streamlit application using Python. I understood how application data can be inserted and retrieved 
rom database collections. I also gained practical knowledge of database connectivity, CRUD operations, and the importance of reliable communication between the frontend
application and the database.
