# DAY 03 – Technology Selection

**Date:** 24/6/2026

Today was the third day of my minor project. I started working on selecting the tools and technologies needed to develop Veltrix AI under the guidance of my project mentor. My mentor explained that choosing the right technologies is important because they affect the working, speed and development of the application.

During the discussion, we compared different programming languages and frameworks that could be used for an AI-based application. After checking their features, ease of use and support for different APIs, I decided to use Python as the main programming language.

For creating the user interface, we discussed different web development tools. I selected Streamlit because it helps in building interactive applications using Python and does not require much frontend coding.

For the AI part of the project, I selected Google Gemini. My mentor explained how AI models can understand user instructions, process questions and provide useful responses. We also discussed how Gemini could be connected to the application using its API.

For storing data, I selected MongoDB Atlas. It provides an online database where contact details, reminder tasks and other project information can be stored easily.

I also explored Twilio for making automatic phone calls and ElevenLabs for converting text into voice messages. My mentor explained that APIs help us connect different services with our application without developing every feature ourselves.

After discussing the available options, I finalized the main technologies that would be used for developing Veltrix AI.

**Work Performed:**

- Researched different programming languages and frameworks with my mentor.
- Selected Python as the main programming language for the project.
- Chose Streamlit for creating the user interface.
- Selected Google Gemini for understanding user instructions and generating responses.
- Learned about the Gemini API and its use with Python.
- Selected MongoDB Atlas for storing contacts and reminder details.
- Explored Twilio for making automatic reminder calls.
- Studied ElevenLabs for converting text into voice messages.
- Compared different tools based on their features and use in the project.
- Finalized the basic technology stack with the guidance of my mentor.
