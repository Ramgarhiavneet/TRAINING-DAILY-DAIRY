DAY 11 – Contact Management Module

Date:6/7/2026

Today, I worked on developing the Contact Management Module of my project, **Veltrix AI – Gemini**. This module plays an important role because the application requires
valid contact information to execute automated reminder calls.

With the guidance of my project mentor, I planned and designed the contact input section using Streamlit. I focused on creating simple input fields where users could enter a
contact's name and phone number. I also considered the importance of collecting accurate phone numbers because these details would later be used by the calling module.

After designing the input fields, I connected the contact management functionality with MongoDB Atlas. The contact details entered by the user were stored in the "contacts" 
collection of the Training database. I tested the insertion process and checked whether the records were saved and retrieved correctly.

During testing, I also explored how stored contact information could be accessed by other modules of the application when executing automated reminder calls.

**Work Performed:**
- Designed the contact management interface using Streamlit.
- Added input fields for contact name and phone number.
- Connected the contact management module with MongoDB Atlas.
- Implemented functionality to insert contact details into the database.
- Tested the contact insertion process.
- Verified stored contact records in the **contacts** collection.
- Explored how saved contacts would be used by the automated calling module.

**Learning Outcome:**

Through this activity, I learned how to develop a basic contact management module using Streamlit and MongoDB Atlas. I understood how user input can be collected, processed, 
and stored in a database. I also learned why accurate contact information and proper database integration are essential for the successful execution of automated reminder 
calls.
